## Context and Sources

- Following the `docs/superpowers/plans/2026-09-28-db-pool-optimization.md` plan.

## Changed Files

- `lib/app-settings.ts`: Cached `getReportSlaDays` and `getPjumPolicySettings` using `unstable_cache`. Added `revalidateAppSettingsCache()`.
- `app/dashboard/settings/actions.ts`: Added cache revalidation on setting updates.

## Decisions

- **Unstable Cache:** Used Next.js `unstable_cache` with a 5-minute revalidation interval and `app-settings` tag to drastically reduce duplicate DB queries.
- **Immediate Revalidation:** Revalidate cache immediately when an admin updates the settings via `updateOperationalSettings` or `toggleMaintenanceMode`.
