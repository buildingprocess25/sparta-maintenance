# Task 6: Add dashboard URL filter and render brand breakdowns

## Purpose
Added the Brand filter to the Admin dashboard and displayed Alfamart and Lawson breakdowns side-by-side when the "Semua" brand is selected.

## Implementation
1. **`app/dashboard/page.tsx`**: Updated to parse the `brand` search param, normalize it with `normalizeStoreBrandFilter`, and pass it to `AdminNewDashboard`.
2. **`app/dashboard/_components/admin/admin-trend-filter.tsx`**: Added a brand dropdown inside `AdminTrendPeriodFilter` to let the user select "Semua", "Alfamart", or "Lawson", preserving the selected period and brand in URL search parameters.
3. **`app/dashboard/_components/admin/admin-new-dashboard.tsx`**: 
   - Passed `brandBreakdown` from `getAdminCommandCenterData` to `KpiGrid` and `StatusDistributionKpis`.
   - Updated `GroupedKpiCard` to accept and render the `breakdown` prop.
   - Displayed Alfamart and Lawson breakdowns side-by-side for Laporan, Penyelesaian, Realisasi & PJUM, and Laporan aktif KPIs when `brandBreakdown` is available.
4. **`app/dashboard/pjum-brand.spec.ts`**: Fixed a TypeScript type narrowing issue in the test logic for StoreBrandFilter comparisons.

## Verification
- Ensured `tsc --noEmit` passes for all modified files.
- The UI filters correctly handle URL parameters and breakdown rendering logic matches constraints.
