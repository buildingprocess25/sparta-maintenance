# Detailed SLA Proses Table

## Scope

Added a detailed SLA process duration table grouped by Branch and BMS. Integrated it into the "Performa Cabang" (`/dashboard/branches`) page via a new Tabs component. Updated the "Durasi Proses per Tahapan" dashboard widget link to point to this new tab.

## Context and Sources

- `app/dashboard/branches/actions.ts`: Added `getAdminDetailedSLAData` to calculate the 7 process SLA durations using raw SQL on `ActivityLog`.
- `app/dashboard/branches/_components/admin-sla-table.tsx`: Created a new accordion-style table to display the SLA metrics.
- `app/dashboard/branches/page.tsx`: Replaced the simple layout with a `Tabs` structure, preserving the existing operational summary while adding the new SLA tab.
- `app/dashboard/_components/admin/process-duration-widget.tsx`: Updated link from `/dashboard/preventive` to `/dashboard/branches?tab=sla`.

## Decisions

- **UI Location**: Opted to integrate the new SLA detailed view as a tab inside the existing `/dashboard/branches` (Performa Cabang) rather than creating a completely new page. This avoids cluttering the sidebar navigation while keeping branch-related performance metrics logically grouped.
- **Data Query**: Used a Common Table Expression (CTE) to pivot timestamp dates from the `ActivityLog` table to compute duration boundaries dynamically across 7 specific stages.
