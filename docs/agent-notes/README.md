# Agent Task Notes

Create one task note for every task that changes files or project decisions.
Do not create one for read-only exploration, status checks, or an investigation
that ends without a changed file or decision.

## Before Starting

Read `AI_RULES.md`, the canonical documents relevant to the task, and recent
related notes in this directory. Verify the current code and schema before
trusting an older note.

## Creating a Note

1. Copy `TEMPLATE.md`.
2. Name the file `YYYY-MM-DD-HHMM-<task>.md` using Asia/Jakarta time.
3. Fill every section with concise, evidence-based information.
4. Update canonical documentation first when the task changes a permanent
   behavior or project decision.

Never include secrets, credentials, raw SQL output, personal data, or
production records.
