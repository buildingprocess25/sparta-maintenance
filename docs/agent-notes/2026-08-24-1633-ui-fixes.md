# Fix UI bugs on BMS Dashboard and Report List

## Scope

- Updated the "Selesai" badge on the Coverage Dashboard to say "Sudah Preventif" and use the `primary` (blue) color scheme.
- Removed the `md:hidden` class on the `BmsReportsMobile` component so that the report list correctly displays on desktop resolutions rather than abruptly vanishing.

## Decisions

- **Badge consistency**: We align the text and style of the completed status with how the store-selection step displays it ("Sudah Preventif" in blue).
- **Responsive design fix**: The `BmsMobileReportsList` had a wrapper with `md:hidden`, which was hiding the only list of reports on the page when viewed on wider screens. Since the parent container limits the layout width anyway, removing this class safely resolves the disappearing content on desktop without affecting mobile layout.

## Verification

- Verified the badge text and color via the React components.
- Verified that the list renders correctly without `md:hidden` using static layout analysis.
