# DB Pool Optimization - Task 6

## Scope

Increased the server draft autosave interval from 10 seconds to 17 seconds.

## Context and Sources

- High concurrency of BMS users creating reports resulted in 300+ DB queries per minute just for autosaving drafts.
- Following the `docs/superpowers/plans/2026-09-28-db-pool-optimization.md` plan, revised to 17s based on user request.

## Changed Files

- `app/reports/(bms)/create/hooks/use-server-draft-autosave.ts`: Changed `SERVER_DRAFT_IDLE_MS` to `17_000`.

## Decisions

- **Interval tuning:** 17 seconds is a sweet spot that reduces DB load by nearly half while keeping draft protection extremely fast and responsive for users in the field.

## Verification

- The change is a simple constant update, no complex types involved.

## Remaining Work and Risks

- None.
