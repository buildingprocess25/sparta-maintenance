# Fix PJUM Addendum Report Date

## Scope

Fixes the report date shown in PJUM addendum pages generated by admin report
intervention. The addendum now matches the normal PJUM PDF behavior by using
the report completion date when available.

## Context and Sources

- User reported that the regenerated intervention PDF changed PJUM recap row
  dates from 20 Agustus 2026 to 18 Agustus 2026.
- Database check showed `createdAt` on 18 Agustus 2026 and `finishedAt` on
  20 Agustus 2026 for the affected reports.
- Existing normal PJUM generation uses `finishedAt ?? createdAt`.

## Changed Files

- `app/dashboard/intervensi/revisi-laporan/actions.ts`: changed PJUM addendum
  row date source from `createdAt` to `finishedAt ?? createdAt`.

## Decisions

- Preserved `createdAt` as the fallback for reports without a completion date.
- Did not change database timestamps because the stored dates were already
  correct.

## Verification

- Reviewed the targeted diff only.
- Test suite was intentionally not run per user request for a fast minor fix.

## Remaining Work and Risks

Regenerate the affected intervention PDF after deploying this commit.
